# Mixer4Track  [Phase 15]

16トラック音楽ミキサーソフト — Phase 15: VUメーター/ピークメーター強化版

## 概要

Windowsローカルで動作する、最大16トラックの音源を読み込み、音量バランスを調整しながら再生・書き出しできる音楽ミキサーソフトです。
8トラックずつ2つのバンクに分けて表示し、ボタン1つで切り替えられます。
Phase 6では MASTER エリア上部にプリセットエフェクターパネルを追加しました。

## 起動方法

### Windows 環境（.exe で起動する場合）
1. 配布された `Mixer4Track.exe` をダブルクリックして起動します。
2. インストールは不要です。

### ソースコードから起動する場合
```bash
pip install pygame PyQt5 numpy pyaudio
python main.py
```

> **注意**: `pyaudio` はマイク入力に必要です。インストールに失敗する場合は `pip install pyaudio` を別途実行してください。

## 使い方

### 1. バンクの切り替え
- **[BANK A: 1-8]** / **[BANK B: 9-16]** ボタンをクリックして切り替えます。
- `Tab` キーでも切り替えられます。
- 切り替え時に自動でプロジェクトが保存されます。

### 2. トラックの読み込み
各トラックの **[LOAD]** ボタンをクリックして音声ファイルを選択します。

### 3. 再生と停止
- **[▶ PLAY]** ボタンまたは `Space` キーで全16トラックを同時再生します。
- **[■ STOP]** ボタンまたは `Space` キーで停止します。

### 4. 音量の調整
縦フェーダーをドラッグ（ダブルクリックで 80% リセット）。

### 5. パンの調整
PAN スライダーを左右にドラッグ（L100〜C〜R100）。

### 6. ミュートとソロ
- **[M]**: ミュート ON/OFF
- **[S]**: ソロ ON/OFF（複数トラックの同時ソロ可能）

### 6.5. マイク入力（Phase 9）
1. トラックの **[MIC]** ボタンをクリックします。
2. デバイス選択ダイアログが開くので、使用するマイクを選択して **[OK]** をクリックします。
3. MICボタンが**青色に点灯**し、マイク音声がそのトラックにリアルタイムで流れます。
4. フェーダー・EQ・エフェクトはマイク入力にも適用されます。
5. **[MIC]** ボタンを再クリックするとマイク入力を解除します。

> マイクとファイル再生は同時に使用できます。

### 7. MASTERフェーダー
右端の **MASTER** ウィジェットで全体音量を調整（0〜150%、ダブルクリックで 100% リセット）。

### 8. プリセットエフェクター（Phase 6）
MASTERウィジェット上部の **FX パネル** で操作します。

1. コンボボックスからエフェクトプリセットを選択します。
2. **[ON]** ボタンをクリックしてエフェクトを有効化します。
3. 全16トラックに同じエフェクトが一括適用されます。
4. エフェクトはEQの後段で処理されます（EQ → Effect チェーン）。
5. WAV書き出し時もエフェクトが反映されます。

### 9. 録音と書き出し（Phase 14）
MASTERウィジェット内の **[REC START]** / **[REC STOP]** / **[EXPORT WAV]** ボタンで操作します。

1. **[REC START]** をクリック→ミックス済み音声の録音開始（再生中でなくても録音可能）
2. **[REC STOP]** ボタンが赤点滅し、経過時間をリアルタイム表示（「REC ● 0:12.3」形式）
3. **[REC STOP]** をクリック→録音停止。**[EXPORT WAV (録音時間)]** ボタンが有効化
4. **[EXPORT WAV]** をクリック→保存先を選んでWAVファイルに書き出し

### 10. プロジェクト保存 / 読み込み
- **[SAVE]**: 上書き保存
- **[SAVE AS]**: 名前を付けて保存（.m4t 形式）
- **[OPEN]**: プロジェクトファイルを開く

- リアルタイム同期：スペクトルデータ・ EQカーブの変更が拡大ウィンドウに即座反映（50ms間隔）
- 同じトラックを再度ダブルクリックした場合は新規生成せず既存ウィンドウを最前面に移動

### Phase 14: REC START/STOP方式EXPORT WAV実装
- **EXPORT WAVボタンを初期無効化**（録音データが生成されるまでグレー表示）
- **[REC START]** ボタン追加（初期有効、緑色）
- **[REC STOP]** ボタン追加（録音中のみ有効、赤色点滅）
- 録音中はREC STOPボタンに「REC ● 0:12.3」形式で経過時間をリアルタイム表示（500ms点滅）
- REC STOP後にEXPORT WAVボタンを有効化し録音時間を括弧内に表示（「EXPORT WAV (0:32.5)」）
- ボタン状態遷移: 初期→録音中→録音完了→書き出し中（全無効）→録音完了
- `audio_engine.py` に `start_rec()` / `stop_rec()` / `get_rec_duration_sec()` / `has_rec_data()` / `export_rec_buffer()` メソッドを追加
- `_chunk_to_sound()` 内でREC ACTIVE中のミックス済みPCMチャンクをバッファに蓄積

### Phase 15: VUメーター/ピークメーター強化
- **`VUMeterWidget`** クラスを新規実装（MASTERトラックの空白部分に配置）
  - 2ch（L/R）セグメント表示（40セグメント、緑/黄/赤）
  - dBスケール目盛（-60〜0 dB、-60/-40/-20/-12/-6/-3/0 dB表示）
  - ピークホールドライン（白線、約3秒ホールド）
  - クリップインジケーター（L/R個別、赤点滅）
  - 「CLIP」ボタンでクリップ警告を手動リセット
  - ダブルクリックで拡大ウィンドウを開く
- **`ExpandedVUMeterWindow`** クラスを新規実装（400×600px、リサイズ可能）
  - 60セグメントの大型表示
  - 詳細dB目盛（0/-3/-6/-9/-12/-18/-24/-36/-48/-60 dB）
  - 現在値dB表示（L/R RMS + Peak）
  - 「CLIP RESET」ボタン、「ピン」ボタン（常に最前面表示）
  - リアルタイム同期（50ms間隔）
- **`audio_engine.py`** に `get_vu_levels()` / `reset_vu_clip()` メソッドを追加
  - `_chunk_to_sound()` 内でミックス済みPCMチャンクのRMS/ピークをリアルタイム計算
  - スレッドセーフ（`_vu_lock`）で保護
  - ピーク値は読み取り後に減衰（メーター側でピークホールドを実施）
