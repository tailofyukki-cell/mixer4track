# Mixer4Track  [Phase 22]

16トラック音楽ミキサーソフト — Phase 23: マスター・リミッター追加版

## 概要

Windowsローカルで動作する、最大16トラックの音源を読み込み、音量バランスを調整しながら再生・書き出しできる音楽ミキサーソフトです。
8トラックずつ2つのバンクに分けて表示し、ボタン1つで切り替えられます。
Phase 6では MASTER エリア上部にプリセットエフェクターパネルを追加しました。

## 機能一覧

### Phase 1 (MVP)
- 4トラック横並びミキサーUI
- WAV / MP3 ファイルの読み込み
- 複数トラックの同時再生 / 停止
- 縦フェーダーによる音量調整（ダブルクリックで 80% リセット）
- 等パワーパンニング（L100〜C〜R100）
- ミュート / ソロ
- キーボードショートカット
- 疑似レベルメーター（ピークホールド付き）

### Phase 2
- **MASTERトラックウィジェット**（TRACK右端に同じ見た目で配置、0〜150%）

- **クリッピング検知と自動補正**
- バックグラウンドスレッドによる書き出し

### Phase 3
- **プロジェクト保存**（SAVE / SAVE AS、.m4t 形式 JSON）

### Phase 4
- **16トラック対応**（Track 1〜16）

- **バンク切り替え時に自動プロジェクト保存**

### Phase 5
- **3バンドEQ**（各トラックにリアルタイムイコライザー）
- LOW / MID / HIGH ノブ操作（各バンドケイパビリティ）

- **プリセットエフェクターパネル**（MASTERエリア上部に配置）

- **EQ → エフェクトのチェーン処理**（リアルタイム再生・WAV書き出し共通）
- **エフェクト状態のプロジェクト保存/読み込み**（スキーマ6.0）

## 起動方法

### Windows 環境（.exe で起動する場合）
1. 配布された `Mixer4Track.exe` をダブルクリックして起動します。
2. インストールは不要です。

### ソースコードから起動する場合
```bash
pip install pygame PyQt5 numpy pyaudio
python main.py
```

> **注意**: `pyaudio` はマイク入力に必要です。インストールに失敗する場合は `pip install pyaudio` を別途実行してください。

## 使い方

### 1. バンクの切り替え
- **[BANK A: 1-8]** / **[BANK B: 9-16]** ボタンをクリックして切り替えます。
- `Tab` キーでも切り替えられます。
- 切り替え時に自動でプロジェクトが保存されます。

### 2. トラックの読み込み
各トラックの **[LOAD]** ボタンをクリックして音声ファイルを選択します。

### 3. 再生と停止
- **[▶ PLAY]** ボタンまたは `Space` キーで全16トラックを同時再生します。
- **[■ STOP]** ボタンまたは `Space` キーで停止します。

### 4. 音量の調整
縦フェーダーをドラッグ（ダブルクリックで 80% リセット）。

### 5. パンの調整
PAN スライダーを左右にドラッグ（L100〜C〜R100）。

### 6. ミュートとソロ
- **[M]**: ミュート ON/OFF
- **[S]**: ソロ ON/OFF（複数トラックの同時ソロ可能）

### 6.5. マイク入力（Phase 9）
1. トラックの **[MIC]** ボタンをクリックします。
2. デバイス選択ダイアログが開くので、使用するマイクを選択して **[OK]** をクリックします。
3. MICボタンが**青色に点灯**し、マイク音声がそのトラックにリアルタイムで流れます。
4. フェーダー・EQ・エフェクトはマイク入力にも適用されます。
5. **[MIC]** ボタンを再クリックするとマイク入力を解除します。

> マイクとファイル再生は同時に使用できます。

### 7. MASTERフェーダー
右端の **MASTER** ウィジェットで全体音量を調整（0〜150%、ダブルクリックで 100% リセット）。

### 8. プリセットエフェクター（Phase 6）
MASTERウィジェット上部の **FX パネル** で操作します。

1. コンボボックスからエフェクトプリセットを選択します。
2. **[ON]** ボタンをクリックしてエフェクトを有効化します。
3. 全16トラックに同じエフェクトが一括適用されます。
4. エフェクトはEQの後段で処理されます（EQ → Effect チェーン）。
5. WAV書き出し時もエフェクトが反映されます。

### 9. 録音と書き出し（Phase 14）
MASTERウィジェット内の **[REC START]** / **[REC STOP]** / **[EXPORT WAV]** ボタンで操作します。

1. **[REC START]** をクリック→ミックス済み音声の録音開始（再生中でなくても録音可能）
2. **[REC STOP]** ボタンが赤点滅し、経過時間をリアルタイム表示（「REC ● 0:12.3」形式）
3. **[REC STOP]** をクリック→録音停止。**[EXPORT WAV (録音時間)]** ボタンが有効化
4. **[EXPORT WAV]** をクリック→保存先を選んでWAVファイルに書き出し

### 10. プロジェクト保存 / 読み込み
- **[SAVE]**: 上書き保存
- **[SAVE AS]**: 名前を付けて保存（.m4t 形式）
- **[OPEN]**: プロジェクトファイルを開く

### Phase 23: マスター・リミッターと実マスター合成
- **MASTERの最終出力にステレオリンク・リミッターを追加**。初期値はON、Ceilingは **-1.0dB**。
- Ceilingは **-0.1 / -1.0 / -3.0 / -6.0dB** から選択可能。瞬時のアタックと120msのリリースでピークを抑制。
- **GR（Gain Reduction）表示**を追加。-2dB以上は黄、-6dB以上は赤で負荷を知らせる。
- ファイルトラックは個別pygameチャンネルではなく、**実際に合成した1本のマスターPCMストリーム**として再生するため、MASTER GEQ、VU、REC、EXPORT WAVに同じ最終出力が反映される。
- `.m4t` プロジェクトにリミッターのON/OFF、Ceiling、Releaseを保存・復元（schema 9.0）。
- リミッターDSP・複数トラック合成・WAV書き出し・設定保存の自動テストを追加。
